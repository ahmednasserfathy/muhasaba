Android-first Flutter skeleton generated with Flutter 3.38.9 / Dart 3.10.8.
The placeholder uses the Arabic locale and Flutter localization delegates for RTL.

From this directory:

```bash
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run
```

An Android device/emulator and accepted Android SDK licenses are required for
`flutter run`, but not for the widget test. See the root README for prerequisites
and verification results. The generated application ID is provisional; release
signing and final branding belong to the release phase.
